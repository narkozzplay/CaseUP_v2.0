# Brand images

Optional design images for the CaseUP Tactical template. Every slot has a gradient fallback,
so the site renders correctly without them. Templates resolve them with `{% brand_asset "name" %}`;
the extension may be .webp, .png, .jpg or .svg.

| Slot | File name | Size |
| --- | --- | --- |
| Header logo (transparent) | logo | 2048 × 512 |
| Favicon | favicon | 512 × 512 |
| Home hero background | hero | 1536 × 1024 |
| Steam login side art | login | 1024 × 1536 |
| Module cover: catalog | module_catalog | 1536 × 1024 |
| Module cover: stats | module_stats | 1536 × 1024 |
| Module cover: farm | module_farm | 1536 × 1024 |
| Module cover: social | module_social | 1536 × 1024 |
| 404 page | not_found | 1536 × 1024 |
| 403 page / closed profile (card background) | access_denied | 1536 × 1024 |
| Link preview (Open Graph) | og_cover | 1536 × 1024 |
